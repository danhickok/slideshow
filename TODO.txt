window.document.querySelector('section.present') gets the current slide

window.document.querySelector('section.present').getBoundingClientRect() gets
everything we need to know about the slide, without querying Reveal.  This is a
DOMRect object with x:37.8, y200.5:, width:1004.4, height: 585.0, top: 200.5,
left: 37.8

But window.document.querySelector('section.present') comes up null in speaker view.

Which window are we working with?
* window.frameElement.parentElement.id == 'current-slide'   -> speaker view: current slide
* window.frameElement.parentElement.id == 'upcoming-slide'  -> speaker view: upcoming slide
* window.frameElement == null                               -> audience view

But that doesn't always work.  It depends on which iframe has focus.
